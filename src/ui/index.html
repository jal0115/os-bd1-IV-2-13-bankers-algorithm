Яаж ашиглах вэ? (хаах бол энд дарна уу)

Banker's Algorithm гэж юу вэ? Банкир зээл өгөхөөс өмнө «бүх хэрэглэгч эцэст нь зээлээ төлж чадах уу?» гэж шалгадагтай адил, үйлдлийн систем нөөц олгохын өмнө «олгосны дараа бүх процесс дуусч чадах уу?» гэж шалгана. Чадахгүй бол олгохгүй. Ингэж deadlock-оос сэргийлнэ.

  1. Өгөгдөл өгнө (1-р хэсэг): «Бэлэн сценари» сонгоно (эсвэл хүснэгтийн тоог өөрөө бичнэ) → «▶ Шалгах».
  2. Нөөц хүснэ (2-р хэсэг): процесс сонгож, хэдийг хүсэхээ бичээд «Хүсэлт илгээх» дарна. Үр дүн: ногоон = олгосон, шар = хүлээлгэсэн, улаан = татгалзсан.
  3. Графыг харна (3-р хэсэг): «▶ Эхлүүлэх» дарж процессууд нэг нэгээр дуусах дарааллыг харна (хурдыг «Удаан / Дунд / Хурдан»-аар солино). Яагаад аюулгүй/аюултай болсныг 4-р хэсгээс шалгана.

1Өгөгдөл: нөөц хэрхэн хуваарилагдсан бэAvailable · Max · Allocation · Need

Хоёр арга бий: А. доороос бэлэн сценари сонгох, эсвэл Б. хүснэгтийн тоог өөрөө бичих. Дараа нь «▶ Шалгах» дарна.

Available = одоо чөлөөтэй нөөцMax = процесс хамгийн ихдээ хэрэгтэйAllocation = процесс одоо барьж буйNeed = Max − Allocation (автомат)
Хүснэгтийн хэмжээ:

2Нөөц хүсэхResource-Request algorithm

Процесс сонгож, хэдийг хүсэхээ бичнэ. Олгосны дараа систем аюулгүй хэвээр байвал олгоно, үгүй бол татгалзана.

⚠ Banker унтраалттай: нөөц хүрэлцэж, Need-ээс хэтрэхгүй бол аюултай хүсэлт ч олгогдоно. Төлөв UNSAFE болж deadlock-д орох эрсдэлтэй.
Үр дүнХүсэлт илгээхэд үр дүн энд гарна.

3Граф: процесс ба нөөцийн холбооResource-Allocation Graph

Цэнхэр сум = процесст олгосон нөөц (тоо = нэгж). «▶ Эхлүүлэх» дарвал процессууд дуусах дарааллаар нөөцөө буцаана. Процесс дээр хулгана аваачвал тасархай сум (Need = цаашид хэрэгтэй болж магадгүй) гарна.

Allocation (нөөц → процесс) Need (процесс → нөөц): процесс дээр хулгана аваачихад гарна

4Аюулгүй дараалалSafe sequence

Процессуудыг ямар дарааллаар дуусгахад нөөц хүрэлцэх вэ. Мөр дээр дарвал граф тэр алхам руу очно.

Сурах бичгийн Safety algorithm (4 алхам)
  1. Work = Available, бүх процессын Finish[i] = false.
  2. Finish[i] = false ба Needi ≤ Work байх процесс i ол. Олдохгүй бол 4-рүү.
  3. Work = Work + Allocationi, Finish[i] = true. 2-руу буц.
  4. Бүх Finish[i] = true бол SAFE, үгүй бол UNSAFE.

5Түүх (илгээсэн хүсэлтүүд)Request log

Хүсэлт бүр дугаартай мөр болж, хамгийн сүүлийнх нь дээр гарна. Request / Release бүрийн цаг, үр дүн, шалтгаан. Тоолуур нь зөвхөн Request-ийг тоолно.
